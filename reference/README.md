# reference

- `carcaca-12x8.jsx`: look and interaction model for the 3D scene (materials, `box`, `iBeam`, orbit and pinch). Port it, do not import it. The polycarbonate walls are not shown on any page.
- `house_steel_frame_asbuilt.html`: layer-toggle pattern (checkbox rows with a colour chip) reused for the trade toggles. It is **not in this repo**: the original names a private residence and this repository is public. Keep a local copy; the pattern is a list of `<label class="row">` with a coloured chip and one checkbox per scene group, bound to `group.visible`.
- Partner logos are **not committed** until the partner confirms in writing (see `data/shared/partners.json`). When they do, drop a clean SVG or PNG at `public/partners/{id}.svg`.
