# Kiver Build pages: hand-off package (final, 4 October 2026)

This folder is the repo root. Open it in Claude Code and say:

> Read CLAUDE.md and SPEC.md. Execute SPEC §17 phase P0. Stop and show me `npm run validate` output and the running dev server before P1.

Then one phase per PR, P0 to P6. P7 is the post-launch loop.

What is decided and where it lives:
- Five models, four at 30 working days and the Max at 45: `data/models/*.json`, generated by `scripts/gen_schedules.py`.
- The 64 page shows the factory as a second scene: `scene_factory` in `data/models/k64.json`, builder spec in SPEC §8.2b.
- Due diligence, partners (MG Projetos included, logos to come), SC rates with SINAPI-SC reference and the 1x to 3x market note, options, Max exits, time-lapse gallery (empty), brand with `igorbuildshouses.com` as future host: `data/shared/`.
- Calls to action and the WhatsApp assistant: `data/shared/cta.json`, `bot/`, `docs/SALES.md`. The bot is a separate service and a separate Claude Code session; start it after P6.
- Cameras: live to the investors' WhatsApp group only; time-lapse on the site after handover; frames for the AI dataset: `docs/CAMERAS.md`.

Things that arrive later and where they go: partner logos → `public/partners/{id}.svg`; partner confirmations → flip `confirmed` in `partners.json`; the first finished build → one entry in `timelapses.json`; schedule corrections from the engineer → `scripts/gen_schedules.py`, regenerate, validate.
